The token tax on Indian languages

The same sentence, translated by humans into 16 languages (FLORES-200, 1012 sentences), counted by 8 real LLM tokenizers. A tax of 3.0 means you pay 3× the tokens of English: 3× the API bill, 3× slower output, a third of the context window. Click a column to sort. Code and method on GitHub.

Dashed cell = over 5% of tokens were [UNK]: the tokenizer dropped that text, so its low count is not a saving. Hover a cell for the 95% bootstrap interval.
